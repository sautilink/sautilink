# SautiLink account messages

These templates support official SautiLink account messages.

If you need help with verification, sign-in or password recovery, follow the
instructions shown on [SautiLink](https://sautilink.com) or use the
[Help Centre](https://sautilink.com/help).

Never share a verification code, password or recovery link in a public issue.
For account help or integration enquiries, use
[SautiLink Contact](https://sautilink.com/contact).
