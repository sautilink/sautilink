Security guardrails

Access is denied unless a policy allows it.

  • RLS on every new tableOwnership and membership checks use the authenticated user ID.
  • Minimum Data API grantsReports and notification creation stay under trusted server control.
  • No secret in the browserThe web client will receive a Supabase publishable key, never a service-role credential.
  • Messages respect blocksBlocked pairs cannot create a conversation or insert new messages.
